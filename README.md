# Taichi 大气与云雾渲染器

这是一个使用 Python 和 Taichi 从头实现的大气、天空与云雾渲染项目。项目不采用路径追踪，主要使用适合 GPU 并行计算的程序化着色、解析近似、查找表（LUT）与体积 Ray Marching，在较高运行效率和直观艺术控制之间取得平衡。

项目的视觉目标不是严格复现现实，而是构建一套可交互、可配置、易于扩展的风格化天空系统，重点表现蓝天、朝霞、晚霞、太阳光晕、层状云、体积云、高度雾和体积光。最终效果可以用于独立图像渲染，也可以导出为天空盒、全景图、天气贴图或大气 LUT，供其他项目使用。

## 项目目标

- 使用 Taichi 在 CUDA、Vulkan 或 CPU 后端并行生成天空图像。
- 支持可控的天空渐变、地平线霞光、太阳圆盘与光晕。
- 支持风格化二维云、2.5D 云层，并逐步扩展到体积云。
- 支持距离雾、解析高度雾，以及基于 Ray Marching 的非均匀体积雾。
- 支持太阳照射下的云体自阴影、银边和云隙光等体积光效果。
- 提供实时或近实时预览，同时支持高分辨率离线导出。
- 将物理参数和艺术参数分离，让画面既可基于自然规律，也能主动风格化。
- 保持模块清晰、参数集中、结果可复现，便于学习和算法实验。

## 非目标

- 不实现通用路径追踪器，也不继承旧光线追踪项目的 BVH、材质或 MIS 系统。
- 第一阶段不追求严格的多次大气散射、完整气象模拟或 AAA 游戏引擎级体积云。
- 不从头实现传统光栅化游戏引擎、场景编辑器或完整的游戏对象系统。
- 不为了形式上的物理准确性牺牲主要视觉效果、可调性和交互性能。

## 计划中的渲染流程

```text
Camera Ray Generation
        ↓
Atmosphere / Stylized Sky
        ↓
Sun Disk and Sun Glow
        ↓
Layered or Volumetric Clouds
        ↓
Distance / Height / Volumetric Fog
        ↓
Bloom, Exposure and Tone Mapping
        ↓
Preview or Image / Panorama / Cubemap Output
```

虽然体积云和体积雾会沿视线进行 Ray Marching，但这种固定步进的体积积分不等同于表面路径追踪。第一版渲染流程不需要 BVH、反射路径或随机多次反弹。

## 分阶段路线

### 第一阶段：程序化风格天空

- 相机与每像素观察方向
- 天顶—地平线多段颜色渐变
- 太阳圆盘、软边和光晕
- 根据太阳高度变化的白天、朝霞和晚霞配色
- 曝光、色调映射、Gamma 校正和 Bloom
- PNG 输出与交互预览

### 第二阶段：风格化层状云

- 二维 Value/Perlin/Worley 噪声与 FBM
- 多层云的尺度、高度、速度和风向
- 云量、覆盖率、边缘软硬和形状侵蚀
- 云顶、云底、背光和暖色边缘的艺术控制

### 第三阶段：雾与空气透视

- 解析距离雾和指数高度雾
- 地平线空气透视
- 随太阳方向和高度变化的雾色
- 天空、云层与前景深度的统一合成

### 第四阶段：体积云与体积光

- 有限高度范围内的体积 Ray Marching
- 三维密度场、天气图和分层噪声
- Beer–Lambert 透射率和简化相函数
- 太阳方向光照采样、云体自阴影和提前终止
- 低分辨率体积缓冲与深度感知放大
- 云隙光和风格化体积光

### 第五阶段：可选的物理大气

- Rayleigh 与 Mie 单次散射
- Transmittance、Sky View 和 Aerial Perspective LUT
- 多次散射近似
- 物理结果与艺术调色的混合

## 技术原则

- 优先选择适合 GPU 的规则计算，减少线程分歧和不必要的数据传输。
- 能解析积分或查表解决的问题，不默认使用高成本 Ray Marching。
- 体积效果先在低分辨率计算，再根据质量需要采用边缘感知放大。
- 物理量在线性 HDR 空间计算，色调映射和 Gamma 校正只在输出阶段进行。
- 随机或抖动采样必须支持固定种子，以便重现画面和比较性能。
- 性能优化以测量结果为依据，不因理论上“更先进”而引入复杂架构。
- 风格参数应直观可调，不把所有外观都隐藏在难以解释的物理常量中。

## 当前状态

项目处于初始化阶段。首个里程碑是完成一个可交互的 Taichi 程序化天空渲染器，能够稳定生成白天、朝霞和晚霞预设，然后再加入风格化层状云。

## 许可证

许可证将在首次公开发布前确定。第三方噪声纹理、参考图和其他素材必须分别确认其使用与再分发许可。
